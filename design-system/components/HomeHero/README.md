# HomeHero

The welcome screen: clear header, org wordmark and mission, the extruded R, and a tile per project.

- Props: `active` (header nav item), `still`.
- Content is fixed to the org's own copy (kicker, tagline, mission, motto); edit `bundle.js` to change it rather than passing ad-hoc text.
- Always followed by the three `ProjectPanel`s in index order.
